DEVELOPER TOOLS

Web Network Inspector

JavaScript

An extensible network waterfall that lives inside your application. Inspect fetch requests, XMLHttpRequest, WebSocket messages, resource timings, and your own application events in one timeline. Add controls, connect your own popups, and restyle it with CSS. Plain JavaScript, bounded in-memory capture, and no runtime dependencies.

ACCESSIBILITY

Open Regard

A modular toolkit for making interfaces more adaptable to the people using them. Its Display module provides configurable display preferences, a native widget, synchronized profiles, and an optional React integration. A dependency-free core lets you bring those preferences into your own interface and design.

RULE ENGINES

clipspyx

Python bindings and a Python-native language for the CLIPS production rule engine. Write rules as Python classes, work with facts, and use asynchronous backward chaining to resolve goals. Fact tracing and rule diagrams help explain what the engine did, while the lower-level bindings remain available when you need them.

KUBERNETES · ALPHA

Kimage

A Kubernetes-native image catalog, builder, and delivery system. Declare an image as a Kubernetes resource, build and verify its OCI artifact, and deliver an immutable image release. Workloads can pin the resulting digest, connecting the image you asked for with the artifact your cluster actually runs.

PRIVACY & SITE TOOLS · PREVIEW

Notabenda

Compliance packs for your site: privacy pages, cookie choices, and agreements that fit your own design. Notabenda brings the required facts, components, and integration checks together so you can prepare a draft and host the results yourself. Optional Cloudflare tools add scoped evidence and document history.
